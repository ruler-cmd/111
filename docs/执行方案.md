## 1. 硬件与引脚

### 1.1 动力配置

- 电机：MG513，12V，减速比 **1:30**，65mm 轮，13 线霍尔编码器。
- 驱动：TB6612 D153C 双路带稳压版。
- 电池：先用 **7.4V**（2S），速度约 0.7 m/s，好调；熟练后再考虑 3S 11.1V。
- TB6612：VM 接 7.4V，GND 与 Blue Pill 共地，STBY 接 3.3V。
- **不要用 ST-Link 的 3.3V 给电机供电。**

### 1.2 8 路灰度：1 路 OUT + 3 路地址

你照片里的模块不是 8 个独立输出，而是 **8 选 1 多路复用输出**：

```text
AD2 AD1 AD0 = 000 → OUT 输出通道 1
AD2 AD1 AD0 = 001 → OUT 输出通道 2
...
AD2 AD1 AD0 = 111 → OUT 输出通道 8
```

所以只需要 **4 个 GPIO**：

| 功能 | 引脚 | 说明 |
|---|---|---|
| 灰度 OUT | **PA8** | 数字输入；PA8 是 5V 容忍脚 |
| 灰度 AD0 | **PB3** | 输出，需关闭 JTAG |
| 灰度 AD1 | **PB4** | 输出，需关闭 JTAG |
| 灰度 AD2 | **PB5** | 输出 |
| TB6612 PWMA | PA2 / TIM2_CH3 | 左电机 PWM |
| TB6612 PWMB | PA3 / TIM2_CH4 | 右电机 PWM |
| AIN1 / AIN2 | PB0 / PB1 | 左电机方向 |
| BIN1 / BIN2 | PB10 / PB11 | 右电机方向 |
| 左编码器 | PA6 / PA7 | TIM3_CH1/CH2 |
| 右编码器 | PB6 / PB7 | TIM4_CH1/CH2 |
| 蜂鸣器 | PB14 | 有源蜂鸣器，高电平响 |
| 按键 | PA0 / PA4 / PB12 / PB13 | 沿用现有 |
| OLED | PB8 / PB9 | 沿用现有 |
| 串口 | PA9 / PA10 | 沿用现有 |
| LED1 / LED2 | PC13 / PA1 | 沿用现有 |

PB3/PB4 初始化前必须加：

```c
GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);
```

保留 SWD，ST-Link 仍可下载。

读取方式：

```c
for (uint8_t i = 0; i < 8; i++) {
    GPIO_WriteBit(GPIOB, GPIO_Pin_3, (i & 1) ? Bit_SET : Bit_RESET);
    GPIO_WriteBit(GPIOB, GPIO_Pin_4, (i & 2) ? Bit_SET : Bit_RESET);
    GPIO_WriteBit(GPIOB, GPIO_Pin_5, (i & 4) ? Bit_SET : Bit_RESET);
    Delay_us(5);  /* 等模拟开关稳定 */
    if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_8)) {
        mask |= (1U << i);
    }
}
```

注意电平：

- 模块标称 5V 供电，OUT 可能是 5V。PA8 是 5V 容忍脚，可以直接读。
- AD0/AD1/AD2 由 STM32 的 3.3V 驱动，如果模块是 5V 供电，3.3V 高电平可能不够稳；**先试 3.3V 给模块供电**，或加 3.3V→5V 电平转换。
- 如果 3.3V 供电时检测距离不够，再改 5V + 电平转换模块。

### 1.3 编码器

8 路灰度只占 4 个引脚后，编码器就有位置了：

- 左编码器 A/B：PA6/PA7 → TIM3 编码器模式；
- 右编码器 A/B：PB6/PB7 → TIM4 编码器模式；
- 编码器 VCC 用 3.3V，GND 共地；
- 13 线 × 30 减速比 = 390 pulse/圈，四倍频 1560 count/圈。

先做 4a/4b 可以不接编码器；冲 4c/4d 时再接，距离控制会稳很多。

## 2. 软件模块

新增：

```text
Hardware/
  Line.c / Line.h       ← 8 路读取、权重、丢线/十字判断
  Motor.c / Motor.h     ← TB6612 PWM + 方向
  Buzzer.c / Buzzer.h   ← 发车提示音
User/
  Track.c / Track.h     ← PID、状态机、特殊元素、圈计时
```

接口建议：

```c
void Line_Init(void);
uint8_t Line_Read(void);          /* 8 位掩码，1 = 压黑线 */
int16_t Line_GetError(void);      /* 加权误差 */
uint8_t Line_IsLost(void);        /* 全白 */
uint8_t Line_IsCross(void);       /* 多路同时黑 */

void Motor_Init(void);
void Motor_Set(int16_t left, int16_t right);  /* -1000..1000 */
void Motor_Stop(void);

void Buzzer_Init(void);
void Buzzer_Beep(uint16_t ms);

void Track_Init(void);
void Track_Start(void);
void Track_Stop(void);
void Track_Task(void);            /* 每 10ms 调用 */
uint32_t Track_GetTimeMs(void);
```

主循环：

```c
Line_Read();
Track_Task();
Menu_Tick();
Menu_Refresh();
Delay_ms(10);
```

OLED 巡线页：

```text
LINE: 00111000
STATE: FOLLOW
TIME: 12.3 s
K1:START K2:STOP K4:BACK
```

KEY1 发车，KEY2 急停，KEY4 返回主菜单并停车。

## 3. 14 天执行表

### 第 1 天：硬件总装与电源

- 固定 8 路灰度、TB6612、Blue Pill、OLED、按键、蜂鸣器。
- 8 路灰度用 3.3V，TB6612 VM 用 7.4V，所有 GND 共地。
- 电机线先不接轮子，架空测试。
- 用万用表确认：
  - 电池 7.4V；
  - TB6612 5V/3.3V 输出正常；
  - Blue Pill 3.3V 正常；
  - 所有模块 GND 导通。
- 验收：上电不发热、不冒烟，OLED 正常显示。

### 第 2 天：4a 传感器显示

- 在 `menu.c` 的巡线页显示 8 路状态。
- 逐路用手/白纸挡传感器，确认对应位在 1 秒内变化。
- 调整灰度模块电位器，让白底和黑线电平稳定。
- 验收：8 路都能单独变化，OLED 无闪烁。

### 第 3 天：电机方向与 PWM

- 写 `Motor_Init()`、`Motor_Set()`。
- 测试：
  - `Motor_Set(300,300)` 两轮前进；
  - `Motor_Set(-300,-300)` 后退；
  - `Motor_Set(300,-300)` 原地转；
  - `Motor_Set(0,0)` 停。
- 如果一侧反转，交换该电机两根线，或改方向宏。
- 找每个电机的启动死区 PWM。
- 验收：两轮方向正确，低速不尖叫，TB6612 不烫。

### 第 4 天：直线 PID

- 8 路权重：

```c
weights[8] = {-7, -5, -3, -1, +1, +3, +5, +7};
```

- 先只用 P：

```c
turn = Kp * error;
left = base - turn;
right = base + turn;
```

- 建议初始：`base=350`，`Kp=12`，`Kd=0`。
- 在 1~2 米直线上调，直到不画龙。
- 验收：直线上能连续走 2 米不脱线。

### 第 5 天：弯道与 D

- 加 `Kd`，建议从 4~8 开始。
- 普通弯道降速到 `base=250~300`。
- 如果弯道反应慢，增大 `Kp`；如果左右摆，增大 `Kd` 或减小 `Kp`。
- 验收：普通 S 弯、90° 弯能通过。

### 第 6 天：发车、停车、计时

- KEY1：蜂鸣器响 100ms → 计时清零 → 电机启动。
- 检测到发车/终点横线：停车 → 计时停止 → 显示 `TIME`。
- KEY2：急停。
- KEY4：停车并返回主菜单。
- 验收：发车有蜂鸣、跑完一圈停车、时间显示正确。

### 第 7 天：十字与断路

- 十字：多路同时黑，锁定直行 200~400ms。
- 断路：全白，保持原方向直行 300~800ms，重新找线。
- 每个元素单独跑 5 次，记录成功次数。
- 验收：十字不拐错，断路不原地打转。

### 第 8 天：直角与连续折线

- 直角：外侧传感器压线、内侧全白，降速差速大转弯。
- 折线：降速、增大 Kp/D，逐个拐点跟随。
- 验收：每个元素 5 次至少 3 次成功。

### 第 9 天：圆弧与 Ω 弯

- 180° 圆弧：PID 连续跟随，外侧传感器辅助。
- Ω 弯：沿外侧逐段转，不能从开口直接切过去。
- 验收：圆弧不脱线，Ω 弯能绕完。

### 第 10 天：六边形环岛

- 进入环岛后锁定一个方向；
- 绕一整圈，回到接点；
- 检测到接点后驶出，不能提前切出。
- 验收：环岛 5 次至少 3 次成功。

### 第 11 天：完整地图分段跑

- 按 30%、60%、90% 设置三个检查点。
- 每次只攻一个检查点，记录脱线位置。
- 调整对应元素的参数，不要一次改多个参数。

### 第 12 天：完整地图 5 次发车

- 每次记录：
  - 电池电压；
  - 最远检查点；
  - 脱线位置；
  - PID 参数；
  - 失败原因。
- 取最好一次成绩，针对失败点调参。

### 第 13 天：稳定性与备份

- 换新电池再跑 5 次，确认不是电压问题。
- 给关键参数做宏定义，方便现场改。
- 准备备用电机、TB6612、灰度模块、杜邦线。
- 录演示视频。

### 第 14 天：Git、文档、答辩

- 整理仓库、README、接线图、测试记录。
- 录屏展示仓库主页、提交记录、作者信息、两个关键提交。
- 按评分点逐条自测。

## 4. 关键算法

### 4.1 8 路权重

```c
static const int8_t weight[8] = {-7, -5, -3, -1, 1, 3, 5, 7};

int16_t Line_GetError(void)
{
    int16_t sum = 0;
    uint8_t count = 0;
    for (uint8_t i = 0; i < 8; i++) {
        if (mask & (1U << i)) {
            sum += weight[i];
            count++;
        }
    }
    if (count == 0) return last_error;  /* 丢线保持上一次 */
    return sum / count;
}
```

### 4.2 PID

```c
error = Line_GetError();
turn = Kp * error + Kd * (error - last_error);
last_error = error;

left  = base_speed - turn;
right = base_speed + turn;
Motor_Set(left, right);
```

### 4.3 状态机

```c
typedef enum {
    TRACK_IDLE,
    TRACK_FOLLOW,
    TRACK_CROSS,
    TRACK_GAP,
    TRACK_RIGHT_ANGLE,
    TRACK_ROUNDABOUT,
    TRACK_FINISH,
    TRACK_STOP
} TrackState;
```

| 状态 | 进入条件 | 动作 | 退出条件 |
|---|---|---|---|
| IDLE | 上电 | 电机停 | KEY1 |
| FOLLOW | 发车 | PID 巡线 | 十字/断路/直角/终点 |
| CROSS | 多路黑 | 直行 300ms | 时间到 |
| GAP | 全白 | 直行 500ms | 重新见线或超时 |
| RIGHT_ANGLE | 单侧压线 | 差速大转弯 | 中间见线 |
| ROUNDABOUT | 环岛入口 | 锁定方向绕圈 | 再次到接点 |
| FINISH | 一圈后横线 | 停车、停计时 | — |

### 4.4 发车/终点

- 发车线是短横线，8 路会同时黑。
- 十字也会同时黑，不能只看“全黑”就停车。
- 建议：
  - 记录发车后时间/里程；
  - 只有超过最小圈时（例如 15s）且再次检测到横线，才认为终点；
  - 如果用地磁/双横线标记，更稳。
- 没有编码器时，用时间 + 状态序列判断；有编码器时用累计距离更可靠。

## 7. 风险与保底

| 风险 | 保底方案 |
|---|---|
| 8 路灰度是 8 选 1 输出，只占 4 个 GPIO | 引脚够，不需要 74HC165 |
| 灰度 OUT 是 5V | OUT 接 PA8（5V 容忍）；AD0~AD2 试 3.3V 供电或加电平转换 |
| 编码器不会用 | 先用时间控制；a/b 不需要编码器 |
| 环岛/Ω 调不稳 | 先拿 4a、4b、Git；c/d 按检查点拿分 |
| 电池电压下降导致速度变化 | 每轮换新电池；记录电压；PID 适应 |
| TB6612 发热 | 不长时间堵转；加散热片；检查电机线 |
| Git 提交太晚 | 今天建仓库，先提交现有 1/2/3 题代码 |
